# @exponetdb/web

The Web App of ExponetDB (Wave 8): a React single-page app on the design
system (`packages/tokens`, `ui`, `ui-patterns`, `ui-data`, `icons`), served
by `serve` on the public origin
([ADR-0019](../../exponetdb-docs/01-architecture/adr/0019-process-roles-and-web-app.md),
[ADR-0030](../../exponetdb-docs/01-architecture/adr/0030-supabase-ui-source-adoption.md),
[ADR-0031](../../exponetdb-docs/01-architecture/adr/0031-web-app-serving.md),
[information architecture](../../exponetdb-docs/11-ui/information-architecture.md)).
It replaced the framework-free app of Waves 3A to 7 in Wave 8 Phase 8.

## What it is

- React 19, TanStack Router (file-based routes in `src/routes`, code-split;
  `src/routeTree.gen.ts` is generated by the router plugin during
  `vite build`, never edited) and TanStack Query, Tailwind v4.
- One engine (C-9): it talks only to `/api/v1`, the `/auth` ceremonies and
  `/oauth`, through the typed client in `src/lib/api/` (over
  `@exponetdb/sdk/operations`). The session cookie is `HttpOnly`; the CSRF
  token is read fresh from its readable cookie for every request (it rotates
  at every re-authentication); requests pause while the re-authentication
  dialog is open and the action runs once more after the proof
  (`withReauth`).
- The server sends a strict CSP (`script-src 'self'; style-src 'self'`, no
  inline code or style, no framing, same-origin requests only) and
  `no-referrer`. No script, style, font, image or QR code comes from another
  origin; the TOTP QR code is drawn locally from the matrix the server
  sends. zod runs jitless (`src/app/zod-jitless.ts`), so nothing probes
  `eval`.
- Untrusted text (names, SQL, catalog text, client names, notes) renders
  through `UntrustedText`, `UntrustedName` or `MarkedCode` only: invisible,
  direction and tag characters are shown by code point; nothing becomes
  markup or a link.
- Truthful states (C-28): every read is a `Readable<T>` rendered through
  `ReadableView`; a failed read never renders as empty.

## Deep links and the address

- `returnTo` after sign-in is an exact allowlist of whole paths and exact
  fragments (`src/lib/navigation/links.ts`), never a prefix match; anything
  else goes to `/account`; a recovery session always goes to `/account`.
- One-time links (`/setup`, `/invite`, `/recover`): the token is read from
  `#token=` only, removed from the address bar and the history before the
  router starts (`holdOneTimeLink` in `main.tsx`), held in memory and
  redeemed once.
- Query values are plain strings (`src/lib/navigation/search.ts`, never
  JSON); the router never writes a percent-decoded fragment back
  (`src/app/router.ts`). The fragment-bound pages `/step-up`, `/approvals`
  and `/credentials` reload on `hashchange`, so no form acts on the previous
  link's subject; the consent page follows the fragment it shows.
- External links the server, the CLI and MCP emit keep working:
  `/setup#token=`, `/invite#token=`, `/recover#token=`, `/login?returnTo=`,
  `/account`, `/approvals#operation=op_…` (opens `/changes/plans/<id>`),
  `/step-up#id=stu_…`, `/credentials#cluster=cls_…&role=…`,
  `/oauth/consent#request=exar_…`, `/oauth/device`, `/oauth/error?reason=`,
  and `/admin/clients`, `/admin/service-accounts` (redirects to
  `/access/oauth-clients`, `/access/service-accounts`).
- A session that ends sends the person to sign in (with the page as a safe
  `returnTo`); on the pages without a session (`/login`, `/setup`,
  `/invite`, `/recover`, `/oauth/error`) only the query cache is dropped.
- `document.title` is "<Page> · ExponetDB" (`src/app/title.ts`).

## Build and tests

```sh
bun run build          # vite build into dist/ (EXDB_WEB_OUT_DIR=<dir> elsewhere), then
                       # scripts/postbuild.ts: served file types only, index.html without inline
                       # script or style, no eval and no foreign origin in scripts, .br and .gz
bunx vitest run        # component tests (jsdom, Testing Library, axe)
bunx tsc -p tsconfig.json --noEmit
```

`bun run test:e2e` at the root runs the built app in Chromium against the
real `serve` role and PostgreSQL 17 (`apps/server/test/*.e2e.test.ts`, the
parity oracle of the Wave 8 order, Appendix C), with zero CSP violations.

## Allowed dependencies

`sdk` (the browser-safe `operations` subpath), `ui-data`, `ui-patterns` and
the UI packages, `contracts` as types only; never a server package
(`tooling/boundaries/graph.json`).
