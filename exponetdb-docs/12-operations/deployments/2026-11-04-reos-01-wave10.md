## Rollback anchor

The schema changed (one additive bundle), so the previous release does not run
on this ledger (`schema_newer`). A return to `4c8c0bc` needs the backup above
restored into `exponetdb-control` first (RB-10; a scratch cluster for a trial
restore needs a bootstrap superuser other than `postgres`), then the tag
`sha256-20b881cba87e407362e6d2470394777f72d45f15299e494be65b2de3ae7910c0` on the
three roles and the `exponetdb-migrate` image line
([`upgrades.md` §1](../upgrades.md)). A fix forward is the usual way.
