# Open decisions raised by agent S7 (network review, promotion and immutability leftovers, CLI sweep, Web accessibility)

- **S7-D1:** who may change an environment's evidence source. Today one person with `registry.manage` plus one passkey step-up can re-point production's `evidenceFrom` to any nonprod environment (no second approval, no cooling period, the audit event lists the field name only). Options: two-person approval for `evidenceFrom` and `tier`; only environments of lower rank; before and after in the audit event.
- **S7-D2:** where "one migration id, one checksum" is enforced: at plan time (today) or also at accept and apply under a project-level unique claim.
- **S7-D3:** an egress policy for the Control Plane host. A holder of `registry.manage` can point the server at any host and port; the answer class (`TARGET_UNAVAILABLE` versus `TARGET_TLS_FAILED`) is a port-scan oracle for a privileged person. Decide whether the product documents a deny-list for the host firewall or adds an address policy for registered endpoints.
- **S7-D4:** monitoring promises for certificates and revoked identities: should a target certificate expiring within 30 and 7 days be a finding, and a revoked node that keeps calling an incident finding?
- **S7-D5:** `node revoke` of the only node is a single-person, step-up-only action (class high, approvals required 0) that makes all backup and host operations of its clusters unreachable until re-enrollment; confirm or require a second person.
