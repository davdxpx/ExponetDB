# TC-002 `node postgres config` and `node postgres roles` cannot be planned from the CLI

Verdict: FIXED. E7's TC-002 part (the CLI does not offer to inspect): fixed; its text-mode remainder belongs to TC-056.

Real stack (`probes/r1-cli-node.host.test.ts`, CLI process over HTTP, no inspection by hand, fresh world):
| command | old CLI | new CLI |
|---|---|---|
| `node postgres config <node> --cluster <cls> --set work_mem=8MB --no-wait` | exit 1, `NODE_OBSERVATION_STALE` | exit 0, plan created, table shows `PARAMETER VALUE EFFECT / work_mem 8MB reload` |
| `node postgres roles ... --file roles.json --no-wait` (create_role + set_role_setting) | exit 1, `NODE_OBSERVATION_STALE` | exit 0, plan `high`, steps listed |
| `node inspect --capability postgres.roles.inspect@2 --arg-json expectSettings=[]` | exit 2 `Unknown flag: --arg-json` | exit 0, operation observed |
| `node inspect --capability postgres.config.plan@2 --arg-json 'changes=[{"name":"work_mem","value":"8MB"}]'` | exit 2 | exit 0 |
| hba, extensions, tls, reload, restart | need a hand-made inspection | exit 0 each (reusable observations reused when younger than 5 minutes, config and extensions always inspect) |
`--no-inspect` with no observation: text mode `Error NODE_OBSERVATION_STALE: ... Inspect the cluster through the node, then plan again.` without the capability; the JSON mode carries `details.capability: postgres.config.plan@2` (E7's remaining half, TC-056).
