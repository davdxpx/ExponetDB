## Diff review
Scope: lexer/parse + tests + docs only. No assertion weakened, no skip. The decoder follows PostgreSQL (doubled quotes, `E` escapes, continuation lines); documented shortcut: `U&''` escapes not decoded (`DO` takes a plain string constant only). Any string that is not a body stays data.
