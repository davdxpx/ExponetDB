This record follows the model in
[`acceptance-gates.md` "How gates are recorded"](../acceptance-gates.md#how-gates-are-recorded)
and the G6 record. Item status values: `open`, `PASS`, `FAIL`, `NOT PROVEN`,
`NOT APPLICABLE` (only with a reason the owner accepts), `WAIVED` (only by the
owner, with a reason and an expiry). Security items (**S**) cannot be waived.
Three columns are kept apart throughout: **contract** (a schema, route,
action or tool exists in `packages/contracts`), **implementation** (a handler
or use case serves it) and **evidence** (a test or a run proved it here, with
the commit). Fixtures never stand in for production evidence; a reference
client never stands in for a real client.

this repository (no GitHub Actions runner starts); no PASS is derived from a
workflow file.**
