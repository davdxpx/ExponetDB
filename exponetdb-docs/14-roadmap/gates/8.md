This record follows the model in
[`acceptance-gates.md` "How gates are recorded"](../acceptance-gates.md#how-gates-are-recorded)
and the G6 and G7 records. Item status values: `open`, `PASS`, `FAIL`,
`NOT PROVEN`, `NOT APPLICABLE` (only with a reason the owner accepts),
`WAIVED` (only by the owner, with a reason and an expiry). Security items
(**S**) cannot be waived. Three columns are kept apart throughout:
**contract** (a schema, route or action exists in `packages/contracts`),
**implementation** (code serves it) and **evidence** (a test or a run proved
it here, with the commit). Mock data in the design-system app never stands in
for product evidence.
**G7 is not accepted yet; it is not a dependency of this wave (order D1) and
this record claims nothing about it. G2 off-host deployment evidence is
still outstanding. CI has never run for this repository (no GitHub Actions
runner starts); no PASS is derived from a workflow file. CI: not waived.**
