An observed limit, recorded in [`failure-and-recovery.md`](../../04-migrations/failure-and-recovery.md):
PostgreSQL's deparse functions (`pg_get_indexdef`, `pg_get_constraintdef`,
`pg_get_expr`, `pg_get_viewdef`) wait for a lock that conflicts with ACCESS

therefore caused with an application transaction holding ROW EXCLUSIVE,
which blocks the migration's DDL but not the catalog reads.
