## 5. Evidence environment (OD-25)

G5 needs real systemd evidence on Ubuntu 24.04 with disposable PostgreSQL 16,
17 and 18 instances; mocks alone do not count. This session runs in an
Ubuntu 24.04 container with Docker (cgroup v1). **[ASSUMPTION]** A
privileged, disposable Ubuntu 24.04 container booting systemd as PID 1, with
PostgreSQL from the distribution's or PGDG's packages, is a real systemd path
for these tests; it is tried first and recorded honestly. If it does not
work, the exact runner needed (an Ubuntu 24.04 VM or self-hosted runner with
systemd, no production data, reachable only by CI) is written here and the
systemd items stay `NOT PROVEN`. No VM, self-hosted runner or production host
is provisioned without the owner.
